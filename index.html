Proyek

01

Read-Assist

Platform audiobook untuk penyandang disabilitas netra. Buku PDF/EPUB diunggah, teksnya diekstrak lalu di-speech-kan otomatis di latar belakang, lalu diakses dengan memindai QR Code yang ditempel pada buku fisik, tanpa aplikasi khusus.

  • Ekstraksi teks dari PDF dan EPUB, lalu dibersihkan dan dipecah per kalimat
  • Generasi audio otomatis lewat antrean, dengan percobaan ulang, lalu digabung menjadi satu MP3
  • Pemutar dengan Web Speech API sebagai cadangan, plus kontrol suara Bahasa Indonesia
  • Mode kontras tinggi, ukuran teks A/A+/A++, dan 27 feature test otomatis
Peran
Solo project
Stack
Laravel, Blade, PHP, JavaScript, Tailwind CSS, SQLite
